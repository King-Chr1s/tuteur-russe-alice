Собеседник — version Groq (avec relais)
=======================================

STRUCTURE (à garder telle quelle) :
  index.html
  netlify.toml
  netlify/functions/grok.js

TU AS DÉJÀ UN SITE NETLIFY DÉPLOYÉ ?
------------------------------------
1. Remplace tes fichiers par CEUX de ce nouveau dossier (garde les sous-dossiers).
   - Via GitHub : remets ces fichiers dans le dépôt (écrase les anciens) et pousse.
2. La clé : dans Netlify > ton site > Site configuration > Environment variables.
   - Idéalement, nomme la variable  GROQ_API_KEY  avec ta clé Groq (gsk_...).
   - Si tu as déjà créé XAI_API_KEY, tu peux la garder : mets-y la clé gsk_...
     (le relais accepte les deux noms). Le plus propre reste GROQ_API_KEY.
3. Deploys > Trigger deploy > Deploy site  (obligatoire pour prendre la clé).

PREMIER DÉPLOIEMENT (si besoin) :
  - netlify.com > Add new site > Import from Git > choisis le dépôt > Deploy.
  - Puis étapes 2 et 3 ci-dessus.

ENSUITE :
  - Ouvre l'URL du site sur le téléphone > Ajouter à l'écran d'accueil.
  - La clé vit côté serveur : rien à coller dans l'app.

NOTE : l'aperçu dans Claude ne peut pas joindre le relais (/api/grok) ;
c'est normal, ça ne répond qu'une fois le site déployé.

MODÈLE : par défaut llama-3.3-70b-versatile (bon en russe). Si Groq le retire
un jour, l'app propose GPT-OSS 120B et Llama 4 Scout dans les réglages (⚙).
